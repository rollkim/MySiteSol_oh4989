## 3. 지도 UI (Npay 부동산)

- **마커**: 상단 면적 뱃지(`98㎡`) + `매 5.5억` + `실 5.1억`(실거래 병기, 녹색) — 매물가·실거래 이중 표기
- **클러스터**: 녹색 원 + 매물 수 (9~423)
- **사무소 마커**: `oh!채영 공인중개사사무소` 라벨 마커 (주황 집 아이콘)
- **3분할**: 좌 목록 패널(카드) / 중앙 상세 패널 / 우 지도 — 디자인가이드 §4-P1과 동일 구도
- 목록 카드: 유형 라벨 + 가격(bold) + 스펙 요약(유형|연차|계약㎡(전용)|층) + 한 줄 소개(따옴표) + `소유자 확인매물 날짜` 배지 + 출처(사무소명·부동산포스)
- **필터 칩**: [전체거래유형▾] [전체매물유형▾] — 매물유형 드롭다운은 취급 5종 체크리스트
- 우측 도구 레일: 단지 / 실거래가 / 평 / 교육 / 편의 / 개발 / 증개 / 거리뷰 / 지도 / 측정
