## 4. 상호작용·동작

- **활성 표시**: 현재 화면의 `key`와 일치하는 항목만 `bg rgba(255,255,255,.12)` + `color #fff`. 나머지는 투명 배경 + `#9FB3BC`. 별도 hover 스타일(`style-hover`)은 사이드바 항목에 정의돼 있지 않음 (관리자 칩 공통 hover 규칙만 README에 존재; 전환 `.12s ease`는 사용자 사이트 절에 명시).
- **문의 건수 배지**: `상담 문의` 항목에만, 미처리(신규) 문의 수를 골드(`#E8C87A`) 원형 pill로 표시. A1 대시보드 KPI "새 상담 문의 3건", A4 탭 "신규 3"과 같은 수치로 동기화되는 값.
- **사이드바 하단 프로필**: 계정 표시 + 로그아웃 진입점. `margin-top:auto`로 바닥 고정. (프로토타입에서는 A1 프레임에만 그려져 있고 A2·A3·A4 프레임은 생략 — 공통 구현 시 포함이 자연스러움.)
- **상단바 우측 CTA**: 전 화면 공통으로 `＋ 매물 등록`(틸 `#146B7C`)이 주 액션. A1은 `사이트 보기 ↗`(새 탭으로 공개 사이트) 병치, A3은 화면 특성상 `손님 화면으로 보기 ↗`(공개 상세 미리보기) + `매물 안내서 뽑기`(인쇄물)로 대체.
- **A3 상단바만 h60**: 좌측이 브레드크럼+제목 2줄 구조라 높이가 4px 큼.

- A3 프레임의 사이드바 메뉴 루프(L336–341)에는 배지 `sc-if` 블록이 **누락**돼 있음(A1·A2·A4에는 있음). 목업 단순화로 보이며, 공통 컴포넌트로는 배지 포함이 맞음.

## 4. 상호작용 · 정책 (README §A4 + 마크업 구조에서 확정)

1. **목록 → 상세**: 좌측 430px 목록에서 행 선택 시 우측 상세 표시. 선택(신규) 행은 좌측 `3px solid #146B7C` 마크 + 배경 `#F6FAF9`, 비선택 행은 마크 `transparent`·배경 `#fff`.
2. **탭 필터**: 전체/신규/연락중/완료 4종, 라벨에 건수 병기(`전체 14` 형식). 활성 탭은 `#0B2430` 채움, 신규 탭만 경고톤(`#FBEDEA`/`#C0392B`).
3. **상세 흐름 순서 (README 확정)**: 이름·연락처·접수 경로 → 전화 걸기 / 문자 보내기 → 문의한 매물 카드(**클릭 시 매물로 이동**) → 문의 본문 → 연락 이력 타임라인(접수 / 자동 회신 / 통화 메모 추가) → 처리 상태 칩(신규/연락중/방문 예약/완료).
